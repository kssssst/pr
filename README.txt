БЫСТРЫЙ СТАРТ
================================================================================

1. СБОРКА НА WINDOWS:
   
   cmake -S . -B build -G "Visual Studio 17 2022" -A ARM64
   cmake --build build --config Release

2. РЕЗУЛЬТАТЫ:
   
   build\bin\Release\TrayApp.exe       (Главное приложение)
   build\bin\Release\TrayService.exe   (Windows Service)

3. ЗАПУСК:
   
   Вариант А: Прямой запуск
   build\bin\Release\TrayApp.exe
   
   Вариант Б: Установка сервиса (требует администратор)
   install_service.bat

4. ИСПОЛЬЗОВАНИЕ:
   
   - Левый клик на иконку → Показать окно
   - Правый клик на иконку → Контекстное меню
   - Меню → "Открыть" или "Выход"
   - Закрытие окна → Приложение продолжает работу
   - Меню "Файл" → "Выход" → Завершение приложения
