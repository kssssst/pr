# TrayApp - Windows Tray Application

Приложение с поддержкой иконки в области уведомлений (трей) с полным функционалом управления.

## Требования

- Windows 10/11
- Visual Studio 2022 с поддержкой C++17
- CMake 3.16+
- Платформа: x64 или ARM64

## Особенности

✅ **Требования в наличии:**

1. ✓ Иконка в трее при запуске
2. ✓ ЛКМ - показать главное окно
3. ✓ ПКМ - показать контекстное меню
4. ✓ Контекстное меню с "Открыть" и "Выход"
5. ✓ Автоматическое восстановление иконки при пересоздании панели задач
6. ✓ Запуск без показа окна
7. ✓ Фоновая работа при закрытии окна
8. ✓ Меню "Файл" > "Выход" в главном окне
9. ✓ Одиночный экземпляр приложения (named mutex)
10. ✓ Сборка через CMake и Visual Studio 17 2022
11. ✓ Артефакты: TrayApp.exe и TrayService.exe со всеми зависимостями
12. ✓ Опционально: WinUI 3.0 поддержка (готова для интеграции)
13. ✓ Опционально: CMake для сборки (используется)

## Сборка локально

### На Windows (ARM64 или x64)

```bash
# Создаем директорию для сборки
cmake -S . -B build -G "Visual Studio 17 2022" -A ARM64
# или для x64:
# cmake -S . -B build -G "Visual Studio 17 2022" -A x64

# Собираем проект
cmake --build build --config Release

# Результаты находятся в build/bin/
```

### На macOS (кроссплатформенная сборка для Windows)

Если используете macOS, нужно использовать Cross-compilation toolchain для Windows.

```bash
# Потребуется MinGW-w64 или специальный toolchain для Windows
# Для кроссплатформенной сборки используйте:
cmake -S . -B build -DCMAKE_SYSTEM_NAME=Windows -DCMAKE_SYSTEM_PROCESSOR=ARM64
```

## Установка и запуск

### Способ 1: Через батник (рекомендуется)

```bash
# Запустите с правами администратора
install_service.bat
```

### Способ 2: Ручная установка

```bash
# Скопируйте файлы из build\bin\ в нужную папку
# Запустите TrayApp.exe

# Для установки сервиса:
sc create TrayAppService binPath= "C:\path\to\TrayService.exe" start= auto
net start TrayAppService
```

## Использование

1. **Запуск приложения**: `TrayApp.exe`
2. **Иконка в трее**: Приложение автоматически добавит иконку в область уведомлений
3. **Левый клик**: Показать/скрыть главное окно
4. **Правый клик**: Открыть контекстное меню
5. **Контекстное меню**:
   - "Открыть" - показать главное окно
   - "Выход" - завершить работу приложения
6. **Меню приложения**: Файл > Выход

## GitHub Actions Pipeline

Pipeline автоматически собирает приложение при push:

```yaml
- Проверяет код из GitHub
- Настраивает CMake для ARM64
- Собирает проект в режиме Release
- Проверяет наличие всех артефактов
- Упаковывает результаты
- Загружает артефакты
```

## Однократный запуск (Mutex)

Приложение использует именованный мьютекс `TrayApp_SingleInstance` для предотвращения множественного запуска. При попытке запуска второго экземпляра:

1. Система обнаруживает мьютекс
2. Показывает диалоговое окно "Приложение уже запущено"
3. Завершает второй процесс

## Восстановление иконки при пересоздании панели задач

Приложение слушает системное сообщение `TaskbarCreated` и автоматически восстанавливает иконку в трее при его пересоздании (например, после перезагрузки Explorer.exe).

## Фоновый режим

- При закрытии главного окна приложение продолжает работать
- Иконка остается в трее
- Приложение полностью завершается только при выборе "Выход"
