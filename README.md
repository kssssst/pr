# TrayApp + TrayService

Windows-проект из двух компонентов:

- `TrayService.exe` - Windows-служба, которая запускает GUI-приложение в пользовательских терминальных сессиях.
- `TrayApp.exe` - графическое приложение с иконкой в трее, главным меню и контекстным меню.

Взаимодействие между приложением и службой выполнено через Windows RPC с локальным транспортом `ncalrpc` (ALPC).

## Возможности

- служба запускает `TrayApp.exe` во всех доступных терминальных сессиях, кроме сессии `0`;
- служба отслеживает новые входы пользователей и запускает GUI в новой пользовательской сессии;
- GUI запускается скрытым: при старте видна только иконка в трее;
- пункт `Выход` в главном меню окна вызывает остановку службы через RPC;
- пункт `Выход` в контекстном меню трея также вызывает остановку службы через RPC;
- при остановке служба завершает все запущенные экземпляры GUI;
- обычные SCM-сигналы `Stop` и `Shutdown` службой не принимаются.

## Сборка

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A ARM64
cmake --build build --config Release
```

Для x64:

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

Результат:

```text
build\bin\TrayApp.exe
build\bin\TrayService.exe
```

Проект собирается со статическим MSVC runtime.

## Установка

Скопируйте оба `.exe` в одну директорию и запустите от администратора:

```bat
install_service.bat
```

Удаление службы:

```bat
uninstall_service.bat
```

## Поведение GUI

Если `TrayApp.exe` запущен вручную и служба остановлена, приложение запускает службу, дожидается состояния `Running` и завершает свою работу.

Если `TrayApp.exe` запущен не службой `TrayService.exe`, приложение завершает работу.

## CI

GitHub Actions собирает проект при push в любую ветку и публикует артефакт `TrayApp-Release` с `TrayApp.exe`, `TrayService.exe`, скриптами установки и документацией.
